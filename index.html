Kode Google Apps Script

Salin kode ini ke Google Sheets Anda (Ekstensi > Apps Script)

Kode Apps Script (`Code.gs`) 
function doGet(e) {
  var doc = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = doc.getSheetByName("DATABASE") || doc.getSheets()[0];
  var cellValue = sheet.getRange("A1").getValue();
  
  var result = {};
  if (cellValue) {
    try {
      result = JSON.parse(cellValue);
    } catch(err) {
      result = {};
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var doc = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = doc.getSheetByName("DATABASE") || doc.getSheets()[0];
    
    var data = e.postData.contents;
    sheet.getRange("A1").setValue(data);
    
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Langkah Deployment Google Apps Script:

  1. Di Google Sheets, klik menu Ekstensi > Apps Script.
  2. Hapus semua kode lama, tempel kode di atas, lalu klik icon Simpan (💾).
  3. Klik Deploy > Deployment baru (New deployment).
  4. Pilih jenis deployment: Web App (Aplikasi Web).
  5. Atur Who has access (Siapa yang memiliki akses) menjadi "Anyone" (Siapa saja).
  6. Klik Deploy, berikan izin akses akun Google Anda, lalu salin Web App URL yang dihasilkan ke input aplikasi ini.
